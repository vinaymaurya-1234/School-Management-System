# School Management System

Full-stack school management system for schools, with role-based dashboards for Principal, Teacher, Student, Parent and Accountant.

## Current phase

- React + Vite frontend
- Role-based mock authentication
- Protected routes
- Responsive dashboard shell
- Separate dashboard for each supported role

## Planned later

- Node.js + Express backend
- MongoDB
- JWT authentication
- Role and permission management
- Students, teachers, classes, subjects and timetable
- Attendance, exams, results and fees
- Admission integration with a school's public website

## Frontend setup

```bash
cd client
npm install
npm run dev
```
